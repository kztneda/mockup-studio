# Sin esqueleto de código

El stack de este proyecto no tiene plantilla de esqueleto:
  - Backend .NET (ASP.NET Core): solo hay plantilla para NestJS.
  - Frontend React (SPA con Vite): solo hay plantilla para Next.js.
  - Base de datos SQLite: solo hay plantilla para MySQL.
  - ORM Entity Framework Core: solo hay plantilla para Prisma.

El resto del paquete (CLAUDE.md, roadmap y specs) sí es válido: pídele a Claude que cree el esqueleto del stack indicado.
